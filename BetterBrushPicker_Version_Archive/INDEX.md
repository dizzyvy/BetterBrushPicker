# BetterBrushPicker — Version Archive

This folder stores the complete BetterBrushPicker development builds in one place for project-history/reference purposes.

Each version is kept as its own ZIP file so the repository does **not** contain dozens of expanded duplicate source trees.

## Current state

**v0.6.0** is the latest build represented here.

Important: v0.6.0 was packaged and statically inspected, but had not yet been runtime-tested in-game at the time this archive was assembled.

## Why this is a ZIP archive

The ZIPs preserve each build without creating a separate expanded folder for every version. Future development can keep the latest working source in the normal project tree while this folder acts as the historical build archive.
